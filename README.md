# VEXA — Packaging & Motion Design Case

VEXA is a fictional, non-commercial packaging and interactive web design study. Four visual editions share one fixed identity system while color, light, material and motion create four different atmospheres.

This repository contains the complete responsive front-end case study and is presented strictly as a creative portfolio project.

## Editions

- **Aurora** — iridescent violet and acid green
- **Noir** — midnight black and raspberry
- **Tide** — deep teal and silver
- **Gold** — warm gold and chrome

## Highlights

- Interactive hero selector for four visual directions
- Scroll-driven reveals and ambient lighting
- Responsive layouts for mobile, tablet and desktop
- Product-design modal views
- Keyboard-friendly interactions
- Reduced-motion support
- Original English-language case-study copy

## Stack

- Next.js 16
- React 19
- TypeScript
- Hand-authored CSS animation and responsive design

## Run locally

```bash
npm ci
npm run dev
```

Then open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

Node.js 22.13 or newer is recommended.

## Structure

- `app/page.tsx` — page structure, edition data and interactions
- `app/globals.css` — visual system, layout and motion
- `public/products/` — optimized VEXA packaging renders

## Project status

Fictional creative case study. The displayed packaging is concept artwork and is not offered for sale.
